# Shinydex - PokéAPI

Proyecto final de Lenguaje de Marcas, realizado en equipo. Es una página web para buscar Pokémon y llevar un registro personal de ejemplares shiny.

## Funciones

- Busca un Pokémon por nombre o número mediante [PokéAPI](https://pokeapi.co/).
- Muestra su imagen normal y shiny, tipos, estadísticas, altura y peso.
- Permite registrar capturas shiny con fecha, juego y número de intentos.
- Filtra y elimina registros. Los datos se guardan en el `localStorage` del navegador.

## Uso

Abre `index.html` en un navegador con conexión a Internet. No hay que instalar dependencias ni configurar un servidor.

El proyecto está hecho con HTML, CSS y JavaScript. En el repositorio también se incluyen el enunciado y la memoria de diseño de la práctica.
